# ai-job-copilot
🚀 AI Job Copilot

An AI-powered job search assistant built using Python and Streamlit to help optimize resumes, identify skill gaps, and manage job applications.

Overview

AI Job Copilot is designed to streamline the job search process by combining resume analysis with practical insights. It evaluates how well a resume matches a job description, gives a score  and highlights areas for improvement.
Features

Resume Analyzer
Compare resume against job description
Calculate match score
Identify relevant skills
Highlight missing keywords
Provide improvement suggestion

🛠️ Tech Stack
Language: Python
Framework: Streamlit
Version Control: GitHub
IDE: Cursor

⚙️ Setup & Installation
-Clone the Repo
git clone https://github.com/sammenon/ai-job-copilot.git
cd ai-job-copilot

-Create a virtual env
python -m venv .venv

-Activate virtual env
Windows powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate

Install dependencies
pip install -r requirements.txt

Run the application
python -m streamlit run app.py

Open in browser
http://localhost:8501
